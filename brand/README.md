# Marca Compras Já — arquivos para GitHub

Use estes SVG no repositório e na organização GitHub.

| Arquivo | Uso |
|---------|-----|
| `logo-github.svg` | **Avatar** do repositório / organização (512×512) |
| `logo-mark.svg` | Ícone / favicon / app icon |
| `logo.svg` | Wordmark completo (fundo claro) |
| `logo-white.svg` | Wordmark para fundo escuro |

## Como colocar no GitHub

1. Abra o repositório → **Settings** → **General** → **Repository social preview** (ou avatar da org).
2. Para avatar da organização: Organization → **Settings** → **Profile** → upload de `logo-github.svg` (ou exporte PNG 512×512 a partir dele).
3. No README, referencie:

```md
![Compras Já](./brand/logo.svg)
```

Identidade visual própria do Compras Já — não utilizar assets do Canal de Compras Brasil.
