# Marca Compras Já

## Paleta oficial

| Token | Hex | Uso |
|-------|-----|-----|
| Grafite institucional | `#171C22` | Cor principal |
| Dourado champagne | `#C9A35D` | Destaques e identidade |
| Preto profundo | `#0E1217` | Header e modo escuro |
| Dourado suave | `#E8D4AC` | Detalhes delicados |
| Off-white | `#FAFAF8` | Fundo principal |
| Cinza porcelana | `#F1F3F4` | Cards secundários |
| Cinza aço | `#68727D` | Texto secundário |
| Branco puro | `#FFFFFF` | Cards e superfícies |

Distribuição visual recomendada: **75%** tons claros · **20%** grafite · **5%** dourado.

Referências em `sources/palette/`.

## Tipografia

- UI / produto digital: **Inter** (Regular, Semibold, Bold)
- A tipografia do logotipo permanece a original da marca
